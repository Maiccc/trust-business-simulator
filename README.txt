TRUST Business Simulator · Prototipo V0.2

Cambios principales:
- Rediseño visual inspirado en la identidad de trustip.lat: base oscura, blanco y acento lima.
- Interfaz responsive pensada desde ahora para futura implementación web.
- Configurador docente reorganizado en 6 pasos con navegación visual lateral.
- Área de simulación con sidebar, jerarquía visual, KPIs, benchmarking y coach pedagógico.
- Se mantiene el motor competitivo funcional de la V0.1.

Uso local:
1. Descomprimir la carpeta.
2. Abrir index.html en Chrome, Edge o Firefox.
3. Configurar la simulación y ejecutar rondas.

Esta versión es un prototipo front-end. Para producción web se deberá separar frontend, backend, autenticación, base de datos y motor de simulación.
